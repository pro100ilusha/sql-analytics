# SQL-аналитика для микро-бизнеса

Учебный проект. SQL-запросы для анализа данных микро-бизнеса по аренде игровых консолей.

## Стек
- SQL: JOIN, GROUP BY, HAVING, подзапросы, CTE (WITH), оконные функции

## Что внутри
- `cohort_analysis.sql` — когортный анализ клиентов
- `metrics.sql` — метрики: средний чек, LTV, повторные аренды
- `schema.sql` — структура базы данных
